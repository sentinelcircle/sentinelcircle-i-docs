Quick Setup

The fastest way to a working setup is the Monitor Setup Wizard (Settings → Monitor Setup Wizard) — it guides you step by step through creating a monitor, choosing its sensors and channels, and reviewing the result. The walkthrough below shows the same result done manually, using a Bluetooth beacon and an Alert Screen as the example, so you can see what the wizard is doing under the hood or set things up your own way.

Details​

Easier option: use the Monitor Setup Wizard in Settings. It walks you through five steps — a welcome page, Create Your Monitor, Select Sensors, Select Channels, and a final review — and lets you add a new sensor or channel on the way. It is only available while monitoring is stopped. The steps below explain the manual approach for reference.

Step 1: Add a Bluetooth Sensor​

  1. Open Settings and tap Sensors
  2. Tap the + button to add a new sensor
  3. Select Bluetooth Beacon as the sensor type
  4. Give it a name (for example "Mom's Beacon")
  5. Tap Select Beacon to scan for nearby devices. The first time, iOS may ask to use Bluetooth or Location — see Permissions explained
  6. Follow the three steps on the screen: put the beacon next to the phone and tap Start, then put the beacon in a closed metal tin and tap Find what changed. The device that vanished or dropped the most is your beacon — tap it, then tap Use This Beacon
  7. Open the Advanced section and set the Alert delay. This is the whole time from the beacon last being heard to the alert reaching you, and Bluetooth needs about the first minute of it just to be sure the beacon is really gone, so the shortest delay the app accepts for a Bluetooth sensor is 71 seconds. The default is 90 seconds; our suggestion is 90–150 depending on how much a false alarm would cost you. See Debounce
  8. Tap Save

Tip: the Bluetooth device should be something the monitored person always carries, like a beacon attached to their keychain or bag. It must keep one fixed identity — a beacon or keyfinder, not a phone, watch or earbuds. A brand-new beacon usually has to be switched on first (pull the battery tab, press its button, sometimes activate it in the maker's app) or it will not be found. See the Bluetooth sensor page for which devices work.

Bluetooth must stay on

This sensor cannot see the beacon while Bluetooth is switched off on the iPhone. If Bluetooth is off or not allowed, the sensor reports that it could not check, and no alert is sent. See the Bluetooth sensor page.

Step 2: Create an Alert Screen Channel​

  1. Open Settings and tap Channels
  2. Tap the + button to add a new channel
  3. Select Alert Screen as the channel type
  4. Give it a name (for example "Screen Alert")
  5. Leave the other options as they are, or choose whether the alert flashes, vibrates and plays a sound — see Alert Screen
  6. Tap Save
  7. iOS may ask to allow notifications — choose Allow, because the Alert Screen reaches you through an alert notification when the app is not open

To be told by Email instead (or as well), choose Email as the channel type, enter the recipient address and the mail account details the channel asks for, and tap Test. See Email channel.

Step 3: Configure a Monitor​

  1. Open Settings and tap Monitors
  2. Tap the + button to add a new monitor
  3. The New Monitor page asks for a name first (for example "Home Safety") — type it and tap Create. The monitor's edit screen opens

  1. Tap Select Sensors and choose your Bluetooth sensor
  2. Tap Select Channels and choose your Alert Screen (or Email) channel
  3. Tap Save. See How Monitors Work

Step 4: Test, then Start Monitoring​

  1. Before you rely on it, run Test on the sensor and on the channel — see Testing

  2. Return to the main screen and tap Start Monitoring

  3. If something is still missing, a permission page titled Before monitoring starts opens first. Allow what it asks for, or tap Skip (Skip for now on a required page) to move on to the next page; on the last page tap Continue

  4. The first time, two notices may appear: Keep the screen on while monitoring? (for Bluetooth, Wi-Fi and Sentinel Area sensors) and Screen Saver. Read them and tap Continue

  5. The final dialog Start Monitoring? has a Trigger on startup option, then Cancel or Start Monitoring

  1. The main screen now shows that monitoring is active

That's it! When the Bluetooth device goes out of range, the app shows the Alert Screen (and sends the email, if you chose that channel).

Keep the app open

iOS limits what an app can do in the background. For the most reliable monitoring, keep the iPhone plugged in with Sentinel Circle open on the screen, keep Low Power Mode off (Settings app → Battery), and keep Background App Refresh on for Sentinel Circle (Settings app → General → Background App Refresh).

Backup and Restore Configuration​

Once you have everything configured, export your settings so you can quickly restore them later if you reinstall the app or set up a new phone.

  1. Go to Settings → Application and tap Export
  2. Tick Include passwords only if you want your email login details in the backup — the file then holds them in plain text
  3. Save the exported file or share it with the iOS share sheet
  4. To restore: Settings → Application → Import, then choose the backup file

Tip: keep a copy of the exported file in a safe place. After reinstalling or on a new phone, importing the backup restores your sensors, channels and monitors in seconds instead of reconfiguring from scratch. A Bluetooth device chosen on another phone, or before an import, must be chosen again on this phone. See Backing Up & Restoring Your Configuration for the full details.
